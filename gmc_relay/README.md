# GMC Relay

Receive a GQ GMC Geiger counter's WiFi upload on port 80, hand it to Home Assistant through a webhook, forward it to gmcmap.com so the public map keeps updating. A sidebar panel graphs the history it keeps: dose rate now, a year's calendar, trends, hour of day and the count distribution. Point the counter's Website setting at the host; nothing else changes. See `DOCS.md`.
